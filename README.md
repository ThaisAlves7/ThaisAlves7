## 🚀 Projetos em Destaque

### 🔹 ETL de Planilhas de Vendas

Pipeline robusto focado em Engenharia de Dados que lê planilhas de vendas com inconsistências, higieniza e valida os dados, rejeitando registros fora do contrato com justificativa integrada e carregando o resultado tratado em um banco PostgreSQL. Um único comando executa todo o processo, projetado para evitar duplicidade de registros (idempotência).

**Principais aspectos do projeto:**

- **Qualidade dos dados:** Validação estrita das regras de contrato com Pandera/Pydantic.
- **Idempotência:** Controle rigoroso do processamento eliminando riscos de duplicidade.
- **Arquitetura:** Organização modular estruturada em camadas de serviços.
- **Infraestrutura:** Ambiente totalmente isolado e conteinerizado via Docker.
- **DevOps:** Estrutura nativamente preparada para esteiras de CI/CD.
